# RoboconYamanashiSim

本リポジトリは，ロボコンやまなし大学部門の競技フィールドおよびロボット「ぺろりん」をUnity上で再現するためのシミュレーション環境である．

## 必要な開発環境

実装を開始する前に，以下の環境を準備する必要がある．

- Git
- Unity Hub
- Unity Editor
- 初回起動時にUnityパッケージを取得するためのインターネット接続

## 製作環境

本シミュレーションの製作に使用したPCの構成は，以下のとおりである．なお，これは動作に必要な最低要件を示すものではない．

| 項目 | 仕様 |
| --- | --- |
| CPU | AMD Ryzen 7 5700 |
| GPU | NVIDIA GeForce RTX 4060 |
| メモリ | 32 GB |

## プロジェクトの導入

1. 本リポジトリをクローンまたはダウンロードする．
2. Unity Hubの「追加」から，本リポジトリのルートフォルダーを選択する．
3. Unity Editorでプロジェクトを開く．
4. 初回のアセットインポートおよびパッケージ取得が完了するまで待機する．
5. Consoleにエラーが表示されていないことを確認する．

必要なUnityパッケージは `Packages/manifest.json` に定義されているため，通常は個別にインストールする必要はない．

## 主なファイル構成

| パス | 内容 |
| --- | --- |
| `Assets/Scenes/Field1.unity` | 従来の競技フィールドを配置したシーン |
| `Assets/Scenes/Field2.unity` | 2026年の寸法図を基に作成したL字型フィールドのシーン |
| `Assets/Scripts` | ロボット制御およびフィールド機能の実装 |
| `Assets/Editor` | フィールド生成やアセット変換に使用するEditor拡張 |
| `Packages/manifest.json` | 使用するUnityパッケージの定義 |
| `ProjectSettings` | Unityプロジェクト全体の設定 |

## 実装時の注意事項

- シーンやアセットを編集する場合は，再生モードを停止してから作業すること．再生中の変更は，再生終了時に失われる場合がある．
- `Library`，`Temp`，`Logs` などはUnityが自動生成するフォルダーであるため，実装対象およびバージョン管理の対象には含めない．
- `.csproj` および `.sln` はUnityによって生成されるため，原則として直接編集しない．
- Field2の形状は大会の寸法図を基にした近似であり，材質の色や摩擦などが実物と完全に一致するものではない．
- フィールドの検証を実施する場合は，未保存の変更がないことを確認したうえで，Unity CLIから `unity command eval_file GolfFieldValidation.cs` を実行すること．
